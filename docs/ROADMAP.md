# Roadmap и известные ограничения

## Известные ограничения (текущее состояние)

- **Память**: heap ядра всего 16 МБ; PMM — наивный bitmap (без дефрагментации/CoW).
  `fork()` копирует адресное пространство поверхностно (стек наследуется, без CoW).
- **Планировщик**: round-robin, без приоритетов, `PROC_MAX = 16`.
- **ФС**: `ntmem_fs` — только чтение, файлы грузятся целиком в память. `ntrfs` — простая.
- **Сеть**: e1000 без прерываний (polling), только Ethernet-кадры (ARP/IP поверх — в
  тестах).
- **GUI**: максимум 8 встроенных окон; пользовательские окна (UWM) без перетаскивания
  (только активация/закрытие).
- **Doom**: собран без звука (`FEATURE_SOUND` не задан — в vanilla-порте нужен SDL_mixer).
- **USB**: только HID-клавиатура; нет USB-мыши/накопителей.
- **Отладка**: паника показывает регистры, но нет backtrace/символов.

## Исправленные баги (история, для контекста)

1. **PMM не резервировал хвост ядра** → таблицы страниц перезаписывали встроенный
   `doom1.wad` → крах Doom. Фикс: `mark_used(0, kernel_end)` + символ `kernel_end` в
   линкер-скрипте.
2. **Мерцание Doom** — рисование в реальный fb + `fb_swap`. Фикс: рисовать в back-buffer
   (`fb_get_ptr`).
3. **Переполнение GUI-буфера** при `pitch > width`. Фикс: буфер по `fb_pitch_px()`.
4. **Смена CR3 во время загрузки ELF** с включёнными прерываниями → порча памяти.
   Фикс: `irq_save()/irq_restore()` вокруг критической секции.
5. **Стек ядра процесса 4 КБ** → переполнение при прерываниях (таймер/USB) → крах.
   Фикс: `KSTACK_PAGES = 4` (16 КБ).
6. **ESC в Doom** «протекал» в GUI и закрывал его (серый экран). Фикс: `keyboard_flush()`
   после выхода из Doom.
7. **Парсер desktop.cfg** оставлял пробел в `EXEC` → `KERNEL://` не срабатывал.
   Фикс: разбиение на поля + тримминг.
8. **`doom_realloc`** читал за границей старого блока. Фикс: `ksize()`.

## План дальнейшей разработки (идеи)

### Высокий приоритет
- Звук в Doom (стриминговый аудио-модуль: микшер Doom → SB16 DMA).
- Отладчик: backtrace по символам (`nm`), dump регистров в panic уже есть.
- Виртуальная память по требованию / swap (пока identity-map 4 ГБ).
- USB-мышь и USB-накопители (расширить xHCI).

### Средний
- Перетаскивание пользовательских окон (UWM) + минимизация/развёртывание.
- TCP/IP стек поверх e1000 (ARP + IPv4 + ICMP уже частично в тестах).
- Многозадачность: приоритеты, sleep-очередь вместо опроса, CoW для fork.
- Файловая система: запись в ntmem_fs, дерево каталогов, дескрипторы.

### Низкий
- Порт большего числа kernel-apps в userspace (terminal/taskman/editor).
- Шрифты/темные темы, растровые иконки вместо текстовых ярлыков.
- Модули ядра (динамическая загрузка драйверов).

## Полезные команды диагностики

```bash
make log                        # tail serial.log
grep -E 'error|panic|FAULT' serial.log
nm build/centcom.elf | grep <symbol>
size build/centcom.elf          # размеры секций
```
